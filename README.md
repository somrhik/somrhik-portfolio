# Somrhik Banerjee — Developer Portfolio

A personal portfolio showcasing my technical skills, projects, education and certifications. Built with Next.js, React and TypeScript, with an emphasis on modern UI design, interactive animations and responsive layouts.

## Live Website

[View Portfolio](https://portfolio-two-sage-5va7vrgbyq.vercel.app/)

## Overview

This portfolio serves as a central place to explore my development journey, technical interests and projects. It features a dark monochromatic design with interactive elements and scroll-based animations.

## Features

- Responsive single-page portfolio
- Animated hero section with visual effects
- About section introducing my background
- Technical skills with animated technology logo carousel
- Project showcase with links to live applications and GitHub repositories
- Education and academic background
- Certifications with verification links
- Contact section with professional social links
- Scroll-based transitions and interactive UI components

## Run Locally

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

Navigate into the project directory:

```bash
cd portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser.
